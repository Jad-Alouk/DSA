## Args:

- all --> Runs all tests simultaneously
- heap --> Runs the heap tests
- sll --> Runs the singly linked list tests
- dll --> Runs the doubly linked list tests

## Input sizes:

| Test | C   | Python |
| ---- | --- | ------ |
| heap | 10M | 1M     |
| sll  | 10K | 100K   |
| dll  | 10K | 100K   |
